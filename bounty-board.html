Протокол претензии на Stellar Wave

1
1. Верифицировать личность
Зайти на drips.network/wave, войти через GitHub, подтвердить identity/KYC и привязать кошелёк. Без этого баллы не начисляются — это главный блокер, и он не технический.
https://www.drips.network/wave
2
2. Выбрать задачу
Задачи с метками «drips-wave» + «N points». Приоритет: complexity: trivial, конкуренция 0 комментариев, всё unassigned.
https://github.com/labels/drips-wave
3
3. Оставить заявку комментарием
Написать в issue: «I'd like to work on this — I can deliver the change and open a PR within the wave window.» Бот drips-wave[bot] автоматически создаёт заявку со ссылкой на панель мейнтейнера.
4
4. Дождаться назначения
Мейнтейнер принимает заявку в панели drips.network (или просто назначает вас assignee'ем). Бот пишет срок сдачи. До назначения PR открывать не надо.
https://www.drips.network/wave/maintainers
5
5. PR → merge → баллы
Ветка от main, Conventional Commits, в описании PR «Fixes #<номер>». CI зелёный → merge → бот начисляет баллы. После закрытия волны баллы конвертируются в долю пула.
Текст заявки, который работает (бот реагирует на любой комментарий, но короткий и конкретный заявку обрабатывают быстрее):
I'd like to work on this one — I can implement it and open a PR with a linked fix and green CI within the wave window.

Что делать прямо сейчас

1. Верификация (блокер). KYC на drips.network/wave. Без неё баллы не идут. Это не техническая задача и решается только владельцем аккаунта — занимает 10–20 минут.

3. Работа. Каждая задача — это добавление примера в README или edge case в тест. Я могу выполнить их целиком через API GitHub и открыть PR.
